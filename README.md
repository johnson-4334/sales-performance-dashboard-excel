# 📊 Sales Performance Dashboard — Excel + AI

An interactive **Sales Performance Dashboard built in Microsoft Excel with the assistance of AI** to transform raw sales data into meaningful business insights.

## 🚀 Project Overview

This project demonstrates how **Excel and AI can be used together to accelerate data analysis and dashboard development**.

The dashboard converts a large sales dataset into an interactive visual report that allows users to explore sales performance across different business dimensions.

## 📁 Workbook Structure

The Excel workbook contains three main sheets:

### 1. 📊 Dashboard

The main interactive dashboard containing:

* KPI metrics
* Sales performance visualizations
* Sales trends
* Regional analysis
* Category and sub-category analysis
* Customer segment analysis
* Ship mode analysis
* Interactive slicers

### 2. 📋 Data

The raw dataset used for the analysis.

* **9,800 records**
* **33 columns**
* Contains sales-related customer, product, order, shipping and regional information.

### 3. 🔎 Analysis

Contains supporting calculations and analytical summaries used to build the dashboard and visualizations.

## 🎯 Key Analysis Areas

The dashboard focuses on:

* 💰 Overall Sales Performance
* 🌎 Sales by Region
* 🛍️ Sales by Category
* 📦 Sales by Sub-Category
* 👥 Sales by Customer Segment
* 🚚 Sales by Ship Mode
* 📅 Sales Trends Over Time
* 📊 KPI-based business performance
